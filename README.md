📖 Sobre o Projeto
A Muskel Fit é uma academia que une treino sério e ambiente acolhedor. Este site foi desenvolvido para apresentar a academia, seus planos, horários de funcionamento e formas de contato de maneira moderna, responsiva e atrativa.

O projeto foi construído com HTML, CSS e JavaScript puros, sem frameworks ou bibliotecas de terceiros, garantindo leveza e performance. O design utiliza uma paleta de cores escuras com detalhes em amarelo, transmitindo energia e profissionalismo.

✨ Funcionalidades
🎨 Design Responsivo: Layout adaptável para desktop, tablet e celular.

📊 Status de Funcionamento em Tempo Real: Um componente inteligente que calcula se a academia está aberta ou fechada com base no horário atual, exibindo um cronômetro regressivo até a próxima abertura ou fechamento.

🗺️ Integração com Google Maps: Mapa incorporado mostrando a localização exata da academia.

💬 Links Diretos para Contato: Botões para WhatsApp e Instagram, facilitando a comunicação.

📱 Menu Hambúrguer: Navegação otimizada para dispositivos móveis.

🏷️ Open Graph Tags: Preview personalizado ao compartilhar o link em redes sociais e mensageiros.

⏰ Seção de Horários: Cards informativos com os horários de funcionamento de cada dia da semana.

🛠️ Tecnologias Utilizadas
Tecnologia	Descrição

🚀 Como Rodar o Projeto Localmente
Pré-requisitos
Um navegador moderno (Chrome, Firefox, Edge, etc.)

Git (opcional, para clonar o repositório)

Passo a Passo
Clone o repositório:

bash
git clone https://github.com/MisterIgorGarcia/Site-muskel-Fit.git
Navegue até a pasta do projeto:

bash
cd Site-muskel-Fit
Abra o arquivo index.html no seu navegador.

Você pode simplesmente dar um duplo clique no arquivo, ou

Usar uma extensão como o Live Server no VS Code para uma experiência com recarregamento automático.

Pronto! O site estará rodando localmente.

🔄 Deploy e Atualizações
O site está hospedado na Vercel e configurado para deploy contínuo. Sempre que uma alteração é enviada para a branch main do repositório no GitHub, a Vercel automaticamente reconstrói e publica o site em segundos.

Fluxo de trabalho:

Faça suas alterações nos arquivos.

Faça o commit e o push para o GitHub:

bash
git add .
git commit -m "Descrição da alteração"
git push
Aguarde ~30 segundos e o site estará atualizado em https://muskelfit-academia.vercel.app/.
